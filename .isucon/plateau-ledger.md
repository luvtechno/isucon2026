# 判断の記録

## いま律速だと判断しているもの
- ベンチマーカー側の処理能力と、各ノードの送信帯域のマイクロバースト制限。アプリの CPU は europe/america で 20〜30% しか使っていない（tmp/prof/b8/*.pprof）。同じ IP の連続するリクエストの隙間が T=45 秒以降に 2ms → 40〜60ms へ広がる（scripts/gaps.py tmp/logs/b8）。

## 律速が競技ホストの外にあると判断したときの実験
- asia の投稿の応答を2秒遅らせて asia の人数を増やさない実験（e5）: 隙間が 4〜10ms に縮まり、europe/america の閲覧役の周回数が増えた。応答の振る舞いで律速の速さが変わる。
- 投稿期間ごとの投稿のソフト上限（f1〜f4）: 上限 54 で 546385 点、なしで約 505000 点。

## 上限だと判断した値
- 人数は1日あたり最大3倍（asia 18→1458、europe 7→567、america 6→486）。実測 tmp/result-*.txt。
- 画像 URL の期限の許容範囲: 上限は now+24h+1分程度（+2分で範囲外）、下限は +12h まで確認（probe）。
